# `sample-fixtures.json`

**This is synthetic data. It is not real historical football results.**

## What this is

300 fictional football fixtures across two invented leagues ("Meridian
League" and "Solstice League", 10 fictional clubs each — none of these
teams, leagues, or results exist), generated by a deterministic script
(`gen-fixtures.cjs`, not checked into this repo — it was a scratch script
run once; see "Regenerating" below to reproduce it) rather than downloaded
from a real source, because this development environment cannot reach the
internet to pull the real Football-Data.co.uk CSVs
`docs/alpha/plans/phase-3-football.md` specifies as the eventual real
backfill.

## How it was generated

1. Each of the 20 fictional teams was assigned a fixed starting ELO-like
   strength (1380-1620).
2. 300 fixtures were scheduled (30 "matchdays" x 5 matches per league),
   spaced 4 days apart, most recent dated 2026-09-13 (`daysAgo: 0`) back to
   116 days earlier.
3. For each fixture, expected goals for both sides were derived from the
   two teams' strength gap (including a fixed +60 home-advantage bump, the
   same convention as `src/lib/alpha/football/elo.ts`) through a logistic
   curve into a realistic 1.0-3.0 expected-goals range, then actual
   `homeGoals`/`awayGoals` were sampled from independent Poisson
   distributions at those expectations — so the data has genuine,
   non-random structure (favorites win more, and by more, on average) but
   real match-to-match variance (upsets happen; Poisson sampling, not a
   deterministic outcome).
4. `closingOdds` were built by inflating each fixture's *true* Poisson-grid
   1X2 probabilities by a per-match overround (uniformly random 4-7%) and
   inverting — i.e. a book that "knows" the true probabilities almost
   exactly but shades its price by a realistic margin, giving `market.ts`'s
   margin-removal something real to remove and a fair (if optimistic —
   real books are noisier than "true prob + margin") baseline for the
   `market` model to beat or tie.
5. All randomness (team pairing shuffle each matchday, Poisson sampling,
   the per-match overround draw) used a single seeded `mulberry32` PRNG
   (seed `20260913`, same algorithm as `src/lib/math.ts`) — not
   `Math.random()` — so the file is exactly reproducible from the
   generator script.

## Fields

```ts
interface SyntheticFixture {
  fixtureId: string;       // "synthetic-<n>"
  date: string;             // ISO date, "YYYY-MM-DD"
  daysAgo: number;          // days before the dataset's own "today" (2026-09-13)
  league: string;
  homeTeam: string;
  awayTeam: string;
  homeGoals: number;
  awayGoals: number;
  closingOdds: { home: number; draw: number; away: number }; // decimal odds
}
```

Fixtures are sorted chronologically ascending (oldest first) so a walk-
forward backtest can slice a training prefix and an evaluation suffix
directly by array index. Note `daysAgo` is relative to the dataset's fixed
"today" (2026-09-13) — a walk-forward fit that uses an earlier cutoff (as
`__tests__/backtest.test.ts` does) recomputes each training match's
days-before-cutoff from its `date` field rather than reusing this column.

## Before trusting any backtest number for anything real

Replace this file with a real backfill (Football-Data.co.uk CSVs for the
top-5 leagues, per `docs/alpha/plans/phase-3-football.md`) before treating
`__tests__/backtest.test.ts`'s RPS/CLV/ROI numbers as evidence of anything
about actual football markets. This dataset exists only to make the
Dixon-Coles fit, ELO update, margin removal, and RPS/CLV/bootstrap-ROI math
exercised by real, deterministic unit tests without needing network access
or API keys — it is intentionally *not* representative of real-world
market efficiency, real bookmaker pricing behavior, or real fixture
scheduling, and no code or comment anywhere in this repo should cite
numbers derived from it as if they described real football betting
markets.

## Regenerating

The generator script is a short (~120 line) standalone Node/CommonJS
script using the same `mulberry32` seeded-PRNG algorithm as
`src/lib/math.ts`, a Knuth Poisson sampler, and the true-probability /
overround construction described above. It was run once with
`node gen-fixtures.cjs > sample-fixtures.json` and its output is this
committed file; the script itself was not kept in the repo since it has no
runtime purpose beyond producing this fixture. Recreate it from this
README's description if you need to regenerate or extend the dataset
(e.g. to add more fixtures, teams, or leagues) — same seed (`20260913`)
reproduces byte-identical output.
